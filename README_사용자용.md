# 🎨 Painter Guide — Meet the Painters

화가에 대해 물어보면 위키백과와 국립현대미술관 자료를 근거로 답해 주는 웹사이트예요.

- 화가 1,343명 (동서양 · 옛날부터 현대까지, 한국 화가 포함)
- 답변 문장마다 [근거 N] 번호가 붙고 눌러 보면 어떤 문서에서 가져왔는지 확인할 수 있어요
- 문서에 없는 내용은 지어내지 않고 "확인되지 않습니다"라고 답해요

---

## ⚠️ 시작하기 전에

| 필요한 것 | 설명 |
|---|---|
| 💾 저장 공간 약 740MB | 설치하는 라이브러리 용량이에요. 설치에 5~10분 정도 걸려요 |
| 🐍 Python 3.10 이상 | 3.12 권장. 터미널에서 `python --version`으로 확인 |
| 🔑 SSAFY GMS API 키 | 질문에 답할 때마다 사용해요. 키가 없으면 화면은 열리지만 질문은 할 수 없어요 |
| 🌐 인터넷 연결 | 새 질문의 위키백과 문서 수집, 작품 이미지 표시에 필요해요 |

> 아래 명령은 Windows 기준이에요.

---

## 🚀 실행 방법 (처음 한 번)

### 1단계. 압축 풀기

zip 파일을 원하는 곳에 풀고, 그 폴더 안에서 터미널(PowerShell 또는 명령 프롬프트)을 열어요.

### 2단계. 가상환경 만들기 + 라이브러리 설치 (약 740MB, 1~3분)

```bash
python -m venv venv
```

```bash
source venv/Scripts/activate
```

```bash
pip install -r requirements.txt
```

### 3단계. API 키 넣기

1. 폴더에 있는 `.env.example` 파일을 복사해서, 이름을 `.env`로 바꿔요
2. 메모장으로 `.env`를 열어 아래 두 줄을 채우고 저장해요

```
WIKI_CONTACT_EMAIL=your-email@example.com
OPENAI_API_KEY=여기에_내_GMS_API_키
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | SSAFY GMS에서 발급받은 키 |
| `OPENAI_BASE_URL` | ✅ | 위 주소 그대로 (끝에 `/chat/completions`를 붙이지 않기) |
| `WIKI_CONTACT_EMAIL` | 권장 | 내 이메일. 위키백과에 문서를 요청할 때 연락처로 함께 보내요 (위키백과 이용 규칙) |
| `MMCA_API_KEY` | ❌ | 비워 둬도 돼요. 미술관 자료는 이미 들어 있어요 |

> 🔒 `.env`에는 내 키가 들어 있으니 다른 사람에게 보내거나 업로드하지 마세요.

### 4단계. 서버 켜기

```bash
uvicorn api.server:app --port 8600
```

`Uvicorn running on http://127.0.0.1:8600`이 보이면 준비 끝이에요.

### 5단계. 브라우저로 접속

👉 http://localhost:8600

처음 접속하면 사용 안내 튜토리얼이 자동으로 시작돼요. 따라 하면서 실제로 질문을 하나 해 볼 수 있어요.

---

## 🔁 다음에 다시 쓸 때

다시 설치할 필요 없어요. 폴더에서 터미널을 열고 4단계 → 5단계만 하면 돼요.

- 끄기: 서버를 켠 터미널에서 `Ctrl + C`

## ✨ 기능 소개

### 1. 화가와 대화
- 오른쪽 위 [화가 선택]을 눌러 화가를 골라요 (한글·영어 이름 모두 검색 가능)
- 대표작 갤러리를 둘러보고, 아래 입력칸에 궁금한 걸 물어보세요
  - 예) *"수련 연작은 몇 점이고 어디 있어?"* · *"말년에는 어디서 살았어?"*
- 답변 속 [근거 N] 배지 → 아래 근거 목록에서 원문 링크까지 확인할 수 있어요
  - 📖 위키백과 · 🏛️ 국립현대미술관 소장품 · 화가 정보(위키데이터)로 출처를 구분해서 보여줘요
- 화가마다 대화가 따로 저장돼요. 다른 화가로 갔다가 돌아와도 대화가 남아 있어요

### 2. 조건으로 찾기
- 화가 이름을 몰라도 조건을 말로 입력하면 찾아줘요
  - 예) *"19세기 프랑스 인상주의 풍경화가"* · *"조선 시대 화가"* · *"현대 한국 화가"*
- 이름을 넣어도 돼요 (예: *모네*). 결과 카드의 [대화하기]를 누르면 바로 그 화가와 대화할 수 있어요

### 3. 화가 비교
- 두 화가와 비교하고 싶은 관점을 입력하면 비교표 + 공통점·차이점을 만들어 줘요
  - 예) 김홍도 vs 신윤복 · 관점 *"풍속화의 소재와 분위기"*

### 그 밖에
| 기능 | 설명 |
|---|---|
| 🔎 오타 검색 | 다반치 → 레오나르도 다 빈치, 김흥도 → 김홍도처럼 이름을 조금 틀려도 찾아줘요 |
| 🖼️ 작품 크게 보기 | 갤러리 그림을 누르면 크게 볼 수 있어요 |
| 🔗 작품 더 보기 | 저작권 때문에 그림이 없는 현대·한국 화가는 미술관·검색 페이지로 연결해 줘요 |
| ⚙️ 근거 검색 방식 | 위쪽 메뉴에서 '유사도'(기본, 정확한 사실 질문에 유리) / 'MMR'(여러 문서에서 고르게)을 고를 수 있어요 |
| ❓ 사용 안내 튜토리얼 다시 보기 | 오른쪽 위 ? 버튼 |

## ⏱️ 알아 두면 좋은 점

- 처음 하는 질문은 10~20초 걸릴 수 있어요. 위키백과에서 관련 문서를 모아 오는 시간이에요. 같은 질문은 다음부터 빨라요
- 답변은 모아 둔 문서 안에서만 해요. 문서에 없는 내용은 "확인되지 않습니다"라고 답해요
- 현대 화가는 저작권 때문에 공개된 작품 이미지가 거의 없어요

---

## 🛠️ 문제가 생기면

| 증상 | 해결 |
|---|---|
| 화면에 "API 키 설정이 없어요" | `.env` 파일 이름이 정확히 `.env`인지(`.env.txt`가 아닌지), 키를 넣었는지 확인하고 서버를 껐다 켜요 |
| "서버에 연결하지 못했어요" | 서버를 켠 터미널이 열려 있는지, 오류 메시지가 없는지 확인해요. 서버는 압축을 푼 폴더 안에서 켜야 해요 |
| `address already in use` / 포트 오류 | 8600번을 다른 프로그램이 쓰고 있어요. 4단계 명령의 `8600`을 `8700`으로 바꾸고, 주소도 `http://localhost:8700`으로 접속해요 |
| `python`을 찾을 수 없다고 나옴 | Python을 설치할 때 'Add Python to PATH'를 체크했는지 확인해요 |
| 화면이 이상하거나 옛날 모습 그대로 | 브라우저에서 `Ctrl + F5` (강력 새로고침) |
